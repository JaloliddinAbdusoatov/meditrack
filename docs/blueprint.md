# **App Name**: MediTrack

## Core Features:

- Clinic Information Display: Display clinic information including address, phone number, email, and a brief description of services offered.
- Service Catalog: List medical services with descriptions.
- Admin Panel: Admin panel to update clinic information, services, and doctors.
- Doctor Profiles: Display profiles of doctors including their specialization, education, and a short bio.
- Contact Form: Allow patients to send a message to the clinic by filling out a form.
- AI Chatbot: Implement a tool that uses a large language model to respond to frequently asked questions using information available in the system.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for trustworthiness and reliability.
- Background color: Light blue (#E8EAF6), very desaturated, to create a calm and professional backdrop.
- Accent color: Purple (#7E57C2), to draw attention and subtly complement the primary.
- Body and headline font: 'PT Sans', a modern humanist sans-serif.
- Use modern and professional line icons for services and information sections.
- Clean and structured layout with clear sections for different types of content.
- Subtle transitions and animations on hover for a smooth user experience.
